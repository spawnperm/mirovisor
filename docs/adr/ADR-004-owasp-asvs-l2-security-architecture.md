# ADR-004: Архитектура соответствия стандарту OWASP ASVS 5.0 Уровень 2

## Статус
Принято (Accepted) · 2026-10-12

## Контекст
Платформа Mirovisor оперирует конфиденциальными данными нескольких изолированных холдингов, финансовых организаций и оборонных проектов. Требуется соответствие требованиям промышленной безопасности OWASP Application Security Verification Standard (ASVS) 5.0 Level 2.

## Архитектурные меры контроля
1. **V1 Архитектура и моделирование угроз**:
   - Принцип наименьших привилегий (Least Privilege) на уровне ролей RBAC (`PlatformAdmin`, `TenantAdmin`, `Developer`, `Viewer`).
   - Изоляция схем PostgreSQL `FORCE ROW LEVEL SECURITY`.
2. **V2 Аутентификация и сессии**:
   - Защита сессий: токены в HTTP-Only Secure SameSite=Strict cookies.
   - Запрет хранения секретов и PAT в открытом виде.
3. **V5 Валидация входных данных**:
   - Строгая runtime-валидация через Zod схем для всех эндпоинтов Gateway.
   - Санитизация идентификаторов схем регулярным выражением `/^[a-z0-9_]{3,63}$/` исключает любые SQL-инъекции при `SET search_path`.
4. **V14 Конфигурация серверов**:
   - Непривилегированный контейнер Node.js (`USER node`, UID 10001).
   - Read-only файловая система в Kubernetes (`readOnlyRootFilesystem: true`).
   - Отключение серверных баннеров (`X-Powered-By`).
